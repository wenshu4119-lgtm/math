# 从计划生成到完整学习计划模块

2026-11-15，基于实际已上线 production-20261115.2 增量建设。题库/讲义扩充、OCR、安卓、收费及外部 AI 继续暂停/关闭。

当前可用：真实报告读取、目标和时间设置、排程预览/保存、内容入口、执行记录、复测重排、版本与 PDF。当前缺口：计划只在下拉框选择；缺名称、用途、执行状态、统筹入口和复盘记录；没有检测报告时不能安排自定义学习事项；重复计划可能误用同一时间预算。

新模块结构：

1. 计划中心：本人/绑定孩子 → 学段/年级/年度 → 计划卡片、搜索、草稿/执行中/暂停/完成/归档。
2. 制定计划：命名和用途；检测驱动、自定义或混合来源；目标/实际时间沿用现有输入与验证；任务预览再保存。
3. 执行计划：当前计划的今日、本周、月历、完整任务和未安排清单。每个范围只有一份当前执行计划，切换时明确提示，防止重复预算。
4. 调整计划：改任务、锁定/推迟/跳过/补做、复制为新草稿、按最新复测预览、历史恢复；已完成记录保留。
5. 复盘：保存每周完成/实际投入摘要、困难和下一周调整；区分自述、执行记录和真实复测证据，不生成虚假掌握或进步百分比。

扩展模型：time_plan_profiles（名称、状态、来源类型、独立范围及时间计划关联），time_plan_reflections（不可变复盘记录，版本化/有理由纠正）。复用既有计划快照、任务事件和权限。每个学生/学段/年级/年度最多一个 active profile，SQL 唯一约束和版本校验保证并发切换。列表/今日/日历只读取授权范围，草稿和归档不加入当前时间预算。

自定义任务写清学习事项、材料说明、估算分钟、完成标准、日期和重复安排；无检测来源必须标为用户自定。支持无目标分的日常学习；未与平台内容建立关系的任务不伪造讲义、题库或评分链接。复用同一个排程引擎，与检测任务共享实际预算。

建设不要求新增题库。验收覆盖旧数据兼容、计划切换并发、暂停/归档、复制不复制实际记录、自定义任务/重复周期/容量不足、今日日历、复盘保存、父母/教师绑定、跨账号、迟到响应和 PDF。正式更新前重新协调发布窗口、备份恢复、加法迁移及回滚，保留所有未提交成果。
