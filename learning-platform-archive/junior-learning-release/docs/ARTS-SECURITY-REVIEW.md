# 艺考发布候选 .2：独立复审与最终验收

日期：2026-11-14。候选：`arts-20261114.2`。旧候选 `.1` 已撤回，不可部署。本文是安全补强后的最新验收，早期测试过程继续保留，不以新结果抹去发现的问题。

## 实际发现并修复的发布阻断项

1. 旧前端仅在401隐藏页面。教师打开私题后换成家长Cookie，再请求打印得到403，旧题干、答案与教师身份仍留在DOM；直接浏览器打印也可能包含旧题。现在401/403/404、授权变化、响应账号不符或缺失均清除内存状态、下拉选项、私人DOM与打印许可，并中止迟到请求。
2. 最终读取曾分两次检查操作者与学生授权。把解绑安排在最后一次操作者查询前，仍可能返回已读取的学生数据。现在最后一条SQL同时检查会话到期、角色、机构、学生有效状态、本人或师生/亲子关系，覆盖详情、列表、证据及打印。
3. 独立复审进一步指出HTML拒绝响应可能先触发JSON解析错误，绕过清除。现在先检查状态与账号响应头，再解析JSON；无效JSON同样清除旧私人数据。

页面隐藏或离开会清空私人状态。返回可见页面、后退恢复时重新认证；旧异步响应不能回写。退出请求失败也清除本页资料，明确提示“服务器退出尚未确认”，不伪称服务端已注销。

私有页面默认打印只输出权限提示。只有用户点击受保护打印按钮，并重新取得当前权限数据后，才获得15秒内一次性打印许可；打印后、过期或页面离开即撤销。公开演示讲义不受私有打印门禁限制。已经合法导出的本地文件无法被服务端追溯撤回，本功能没有作此承诺。
