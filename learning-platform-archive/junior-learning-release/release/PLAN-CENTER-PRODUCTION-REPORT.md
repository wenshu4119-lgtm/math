## 本次完整模块范围

| 环节 | 已实际实现 |
| --- | --- |
| 计划中心 | 命名、计划卡片、搜索、来源/状态展示、复制；草稿/执行中/暂停/结束/归档，历史不删除 |
| 制定 | 检测驱动、自定义、混合三种内容来源；考试目标或无分数的日常学习；复用原日期、目标、时间口径和高级约束 |
| 自定事项 | 自填真实材料说明、完成标准、估算时长、优先级、线上/线下、日期窗口及每周重复；不生成虚假平台讲义/试题/测评分数 |
| 统筹 | 同一孩子/学段/年级/年度只启用一份执行计划；切换明确暂停前份，两个计划均保存版本和审计；不把草稿叠加到当前预算 |
| 日常执行 | 今日、周计划、月历、任务清单、未排入清单；材料入口、执行记录、跳过/补做、推迟和锁定 |
| 持续调整 | 自定计划按当前事项重排；检测/混合计划按目标科目的新报告预览调整，确认后生效；保留已完成记录和锁定事项 |
| 复盘 | 每周保存执行/填报摘要、困难和下一步，纠正追加新记录，原文保留；不把叙述或完成勾选当掌握改善 |
| 跨设备与输出 | 保存计划的受保护直接链接，返回/刷新恢复原孩子和范围；总/周/日 PDF，含自定材料和适用复盘；权限重验与默认拒绝直接打印 |

无报告也可以制定自定义日常学习计划。考试模式保留原分值上限、总和校验和湖北史地政等级分说明；日常模式不要求或保存分数目标。资料文字由用户提供且标注来源，未用 AI 自动生成内容。复制始终新建草稿，复制配置/安排和报告引用，不复制实际执行、复盘或作答。

旧版保存的计划不会批量自动激活。读取为“历史计划，待设当前”；用户明确设置当前或保存设置后建立资料。暂停、结束和归档不删除实际记录，“已结束计划”也不表示所有任务已完成或掌握。

## 原范围与保留事项

真实报告适配仍为初中旧初一年级数学/英语检测与复测（4 点、4 份短讲解、12 题），以及艺考当前机构/年度已审核的首批六科（6 点、6 讲义、18 题）。原审核及新一轮检测依赖保留，不把自主题库核对记录当正式检测。初二、初三可用自定学习计划，但尚未因此获得新的平台持久检测报告适配。

没有扩题、扩讲义或恢复 self-study-loop；原题库总量、旧 math、DeepTutor、代理和已有未提交成果保留。OCR 未开通，安卓暂停，真实收费/推广/企业微信及自动消息未启用。不同范围的独立计划不混在一个日历；目前仅保证选定范围内的单一执行预算，不声称跨所有年级/年度做了全局时间冲突排查。
