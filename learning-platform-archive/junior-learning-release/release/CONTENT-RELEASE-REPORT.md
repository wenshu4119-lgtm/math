## DeepTutor 真实上线范围

现有DeepTutor v1.7.2、自托管Qwen3-0.6B生成模型与Qwen3-Embedding-0.6B保持回环、鉴权和独立资源上限。新增教师桥接也仅回环且要求私有令牌，系统服务限制只访问本机网络；模型配置若改变为非指定本地地址，会拒绝运行。本轮没有外部模型付费、注册或真实学生数据发送。

真实测试证据包括：两份原创TXT实际导入并建索引约24.91秒；两条1024维embedding；原文与SHA匹配的检索引用。部署后使用**实际已部署API + 实际桥接 + 实际模型**，账号和数据库仅在内存隔离环境：数学返回3约30秒，英语返回is约13秒，范围外预设拒答且模型调用0。先前She/am错误保留为阻断回归；坏答案隔离，不自动修成成功。

教师网站仅开放两个固定原创样例及范围外拒答测试，不能接收自由文本或学生资料。它不是完整自由问答、全科RAG、出题或PDF解析服务。生成题目与AI正式评分未开放。现场桥接峰值约167.4MiB，低于350MiB上限，NRestarts为0；这不是大规模并发或教学准确率认证。
