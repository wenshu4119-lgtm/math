## 仍属模拟、仍未开启的部分

三级身份、合成客户、订单、付款核验、退款、奖励、等级与兑付状态全部属于演练，不是实际成交或收入。所有金融记录带simulation约束，不能通过请求或环境变量启用真实模式；生产初始化未创建任何演练成员、客户、订单、授权或联系资料。

默认规则为：一级5%、单笔100元；二级3位不同合格直接客户、8%、150元；三级10位及身份／服务规范／协议模拟审核、10%、200元。人数、比例和上限可在模拟后台提出版本调整并由另一经理复核。30天归因、14天观察和10000元机构月预算均为未确认演练参数；月预算不是个人收益承诺。

只算本人直接推荐，没有上级、下级或团队提成，没有入门费、购买资格费或囤货要求。在线合伙人只是身份名称示例，不赋予股东、法定合伙人、加盟或劳动关系。历史订单保留当时规则；200元减去50元合格退款后按5%得7.50元。CSV金额保存为整数分，界面和PDF以元显示。

当前由工作人员录入“模拟客户本人决定”并双人复核，不是真实客户自助授权或身份验证。案例固定业务线，一位合成客户仅有一条活动归因；真实跨业务线归因细则仍需确认。不同合成ID的去重和已知相关账号防自返，不能声称识别全部真人多账号。成年学员资格未核验，学生账号暂不进入推广演练。

已兑付后的退款和错误记录只追加人工协议处理差额，原凭证保留，不自动扣款、追收或假称已结清。没有网站支付、钱包、提现、自动分佣、自动转账、自动消息或微信零钱到账能力。真实合作申请、活动、带佣渠道和付费宣传没有启用。

## 企业微信实际能力

本次未接企业微信API，未核验企业主体认证、联系我／客户联系／获客／客服权限，未读取客户或发送消息。部署核查未发现相关运行配置键；这不等于用户没有企业账号或认证失败。

填写入口只接收公开联系资料草稿：官方work.weixin.qq.com的获客／客服链接，或管理员提供的真实PNG。上传只做格式、CRC、尺寸、大小和权限校验；没有把合成测试图当真实企业二维码，也没有核验任何真实二维码的归属或可用性。客服链接不等于添加企业微信好友。草稿不公开，保存后所有真实接入标志仍为false。

公开咨询按钮保持“咨询方式准备中”。素材二维码只指向本站两条无归因参数的公开体验链接，明确不是企业微信码。微信外链、跳转及带佣渠道不能因二维码可解码就视为平台允许；素材标“内部审核示例·未批准投放”，不能当作已获准宣传。

用户后续需提供真实经营主体、实际交付服务清单、价格／合同／退费说明，以及企业微信公开链接或二维码；不要提供CorpSecret、支付密钥、客户资料或孩子信息。真实服务分类、主体资质、广告与传播渠道、收费和预收费规则、奖励协议、税务／实名／最低限额、允许的人工兑付渠道须按实际情况确认。武汉线下收费标准不能直接套用于全国线上工具服务。
