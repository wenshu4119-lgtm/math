主题：等式性质与一元一次方程的方法。
等式两边同时加上或减去同一个数，等式仍成立。两边同时乘以或除以同一个非零数，等式仍成立；除数不能为零。只改变一边通常会破坏相等关系。
解一元一次方程的目标是把未知数单独留在一边。消去常数项，再处理未知数前的非零系数；每一步都必须保持等式成立。所谓移项变号，来自等式两边同时加上或减去同一个式子，并不是只移动一个符号。
解出未知数后，将结果代回原方程，检查左边和右边是否相等。代入检验只能验证这个候选值是否满足原式。
如果变形后得到恒成立的等式，可能有无数个解；如果得到矛盾的等式，则无解。不能遇到零系数就直接除以零。
For a linear equation, apply the same operation to both sides. Division requires a nonzero divisor. Isolate the variable and check the result by substitution into the original equation.
