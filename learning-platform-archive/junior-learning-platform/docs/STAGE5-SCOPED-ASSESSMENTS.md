# 第五阶段：内容覆盖盘点与专项筛查

日期：2026-11-14。先核查AGENTS、未提交工作、第四阶段与最新专项报告；只在独立平台本地工作。阶段前源码快照为.local/stage4-before-scoped-assessments，旧math和并行原型只读。

## 当前真实覆盖（实施前）

数学2点：一元一次方程等式性质、有理数分数加减；英语2点：一般现在时be动词、第三人称单数。每点1份讲解、1张记背卡、筛查/练习/复测各1道选择题，故每科6题，总计12题、4份讲解、4张记背卡。普通本地库当前版本审核0条，4点均待真人教师审核；自动化测试的审批不计为真人审核。没有年级/教材版本完整覆盖、题库编写后台或批量历史导入。

学习包为rule-v1：从实际已提交错题提取知识点，无错题则巩固此次范围；材料来自版本快照。老师可调整同科目已审核范围和指导语并批准，之后练习再复测。没有LLM实时生成内容。学生本人作答、教师代录及人工阅卷、家长摘要、管理员账号/关系管理均有真实API，具体能力和边界见下方最终验收。

DeepTutor真实运行仅限隔离的固定上游模块行为实验，以及独立SQLite FTS5词面检索基线；src/retrieval-contract.mjs是失败时关闭的内部边界，没有对学生开放的知识库接口。capabilities明确rag=false、questionGeneration=false，正式评分未接入DeepTutor通用判分。完整解析/Embedding/索引、FastAPI/WS、引用质量及模型出题仍有缺口。可选本机Tesseract OCR已接入，但只产待核对文字，不评分；默认运行和Cloudflare没有OCR供应方时仍不可用。

## 选择与实施约定

选择“已审核知识点专项筛查”，因为现有全科示例筛查要求同科目全部点完成审核：只审核方程时，数学筛查仍409且不创建记录，已通过隔离API复现。先允许有限范围试教，比继续扩大待审核题目数量或接入未验证模型更直接改善当前使用。保留原全科示例入口和审核规则；不宣称专项覆盖整个学科。

计划修改：src/learning.mjs及新增范围辅助模块；public/app.js、范围展示辅助模块、print-data.js、sw.js；OpenAPI生成器/契约、相关测试及交接文档。内容数量不变，既有4份数据库迁移不变：范围模式、知识点标题与版本附加到已有attempt_items.snapshot_json，旧记录不改写。未保存范围标签的历史记录明确标legacy，不能猜成全科筛查。

契约拟新增POST /attempts的可选knowledgeIds，仅diagnostic可用，必须非空、去重、同科目且当前机构已审核；练习/复测仍严格来自学习包。省略字段保留原默认行为。Attempt/清单/Growth的已有记录增加scope元信息；范围只由服务器根据选题快照生成，客户端不能提交成绩、题干或scope快照。

验收要求：只审核一个点即可完成专项筛查→老师批准学习包→练习→复测；其他点不审核也不评分。默认全科示例仍不能绕过审核，混科/未知/重复/空范围拒绝，越权/撤权边界保留。范围标题和版本须冻结；旧记录可读；学生/老师来源区分。桌面/手机真实UI、API契约、D1本地运行和受影响PDF验证；25类导出入口及JSON/CSV保留，未覆盖不补零、未复测不推断进步。

上述为实施前约定，以下是已经完成的结果。

## 已完成的里程碑

学生与老师的「学习与通关」新增「按知识点做专项筛查」。未审核知识点禁选，所选点仍由后端逐个检查机构级审核；只审核一个点即可实际筛查、匹配包、由老师批准、完成练习和复测。原默认全科示例入口保留且仍执行原审核门槛，没有把未审核内容开放给学生。

数学实际演示：只审核方程，方程筛查0/1 → 匹配仅方程的学习包 → 老师批准 → 练习1/1 → 复测1/1；分数点仍未审核且不计入此轮，不制造弱项或样本。英语用只审核be动词的专项验证教师代录，source=teacher_recorded；学生自答为student_self。所有示例分数仅存在隔离测试中。

范围模式/标题/版本保存在现有题目JSON快照。GET单份、清单和成长读取相同历史范围；目录改名或升级不改变已有范围标签。旧记录缺少新字段时标legacy，标题可为null，使用原ID并说明未保存选择模式；没有把当前目录名称或全科范围倒填到历史。未新增迁移，既有0001–0004继续有效，正常库无需数据改写。

API升级1.4.0，仍44路径；新增可选请求字段knowledgeIds和响应scope。生成器、OpenAPI、契约测试同步。严格响应校验客户端需更新契约；旧请求仍有效。未新增保存实体，25类PDF/打印仍齐备，原JSON/CSV没有改掉；测评报告、记录清单、成长时间线打印会显示保存范围。
