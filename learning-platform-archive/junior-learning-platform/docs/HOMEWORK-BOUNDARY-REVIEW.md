# 独立作业闭环边界审查

日期：2026-11-14。此文为主任务实施前的只读研究，不代表作业模块已经实现或测试通过。本子任务只读取新平台代码/交接材料并新增本文；没有修改src/public/migrations、旧math或Antigravity原型，没有运行部署、推送、生产操作或模型服务。

## 1. 现有可沿用能力与需要增加的边界

| 现有代码 | 可沿用 | 新作业不能直接继承的假设 |
|---|---|---|
| src/security.mjs 的authenticate / allowStudent | 服务端会话、Origin/CSRF、机构与师生/亲子绑定 | allowStudent只证明绑定，**不证明是该作业负责老师**。作业owner约束需另加到所有详情、列表、摘要、成长聚合、sheet与导出路径 |
| src/learning.mjs 的approvedTopics与题目快照 | 本机构/版本审核、服务端选题、历史答案快照 | 现有练习/复测不是独立作业；作业提交不能伪装成attempt或自动推进pack状态 |
| src/papers.mjs 的calculatePaperReport | 明确满分、整数百分位、人工部分分、不能混入0–3观察 | 借用计分校验不等于复制纸卷证据或直接套取paper总分。作业应有独立source/状态/反馈 |
| src/papers.mjs 的write_token门控事务 | revision竞争失败后不覆盖明细；确认一次 | 每个后续INSERT/DELETE/audit都须受本次写令牌约束，不能只在batch结尾检查UPDATE changes |
| public/print-data.js / print.js | 当前账号重新读取、X-Actor-Id、一致性复查、A4排版 | print.js只要题目对象含correctOption就会绘制答案。**sheet必须在服务端永远去掉答案/解析**，不能仅靠CSS或模板隐藏 |
| scripts/local-db.mjs / tests/browser-harness.mjs | 真实SQL迁移、隔离SQLite、真实HTTP/UI回归 | 仅Node适配器测试不能证明D1并发语义；高风险状态转换宜再做workerd本机验证 |

当前只有`/packs/{id}/worksheet`和export kind `assignment`通关练习作业单；应继续保留。新模块采用独立路径/导出kind，不能复用名称后悄悄改变旧入口语义。

## 2. 最小状态与可见性

| 状态 | 负责老师且仍有绑定 | 学生本人 | 关联家长 | 成长数据 |
|---|---|---|---|---|
| draft | 可读/改/发布；教师参考答案可见 | 不可见 | 不可见 | 不进入 |
| published | 可读；不再改题目、分值、收件人 | 可读无答案作业并提交 | 仅标题、科目、期限、待交状态等摘要 | 不进入 |
| submitted | 可读真实作答并人工批改 | 可读本人已提交作答；答案仍隐藏 | 仅已提交/待批改摘要，分数必须null | 实际提交事件进入，未批改不能造0分或平均分 |
| graded | 只读批改结果；更正另设流程 | 可读分数、反馈和此时允许的标准答案/解析 | 仅总分及明确可公开的家长摘要 | 人工成绩更新同一作业证据，不生成第二份提交 |

其他已绑定但非负责老师默认不可读写该作业；管理员不默认读学生作答。若以后要协作教师，应显式设计授权，不通过growth/摘要绕过owner约束。

撤销绑定后：老师失去该作业访问权；学生可保留本人历史读取，但新提交须再次确认负责老师仍active且师生关系仍存在，防止继续向已经撤销的授课关系收集作答。父母权限只由当前亲子关系决定，撤销后后续摘要/打印请求应失败。若采用不同业务规则，应在API与测试中明确，而不是由不同端点偶然决定。

## 3. 内容与答案保护

1. 创建只接受题目ID/分值等必要字段，服务端从本机构已审核、同科目的practice题构建快照。不能接受客户端题干、答案key、解析、score、reviewed_by或role覆盖。
2. sourcePackId如存在，应核对同学生、同科目、已批准状态、版本和选题范围。不得仅凭“老师绑定了两个学生”就引用另一个学生的包。
3. 草稿发布前重查审核版本与题目内容一致；发布后只读快照。此后题库内容变化不得改写既有作业。学习包状态从approved进入in_progress不应自动让已发布作业失效，也不应由作业提交去修改该状态。
4. 角色专用DTO采用白名单。学生未graded时，所有JSON层级都不得含correctOption、rationale、原始snapshot_json、teacher-only feedback草稿或嵌套source快照里的答案。
5. `/sheet`即使由教师调用也只给题目/选项/分值/说明，永不含标准答案、解析、学生作答或批改内容，适合发给学生打印。教师含答案的审阅导出另起明确名称。
6. 初期题库很小，学生可能在以前已完成的练习中见过同一道题；“本次未提交答案保护”不能宣传为防作弊或完整测量效度。独立作业分数不是复测进步。

## 4. 提交、批改与事务

- 每份作业一个学生，学生才能提交；教师不能通过该端点冒充学生提交。线下代录保留原人工阅卷/教师代录入口，不能混成student_self。
- 答题集合必须与快照一致：拒绝缺题、重复、额外题、越界选项、空/非对象答案、客户端分数。文字过程设长度上限，作为数据渲染，不执行HTML或指令。
- 发布/提交/批改均使用状态+revision条件更新。后续作答/分值/审计写入需同一事务且由随机write_token门控；失败方不能删除获胜请求的内容。
- 对需要“撤销立即生效”的写操作，建议在UPDATE谓词中同时加入当前owner/active/relationship的EXISTS条件，避免鉴权读取到提交之间的撤销竞态。
- create/submission/grade requestId分别明确作用域。重复同语义内容返回已有结果或明确冲突，但绝不新增成长/答案/批改/审计事件。相同requestId换学生、答案或分值必须409。
- 幂等回放比较内容哈希应在revision冲突处理前；requestId/revision是传输守卫，可不纳入语义哈希。已提交/已批改后的合法网络重试不能要求重新作答。
- 批改必须逐题明确分数，0分是合法值，空值不能被Number('')变成0。最多两位小数、0≤earned≤已发布max，服务器整数百分位求和。
- 教师总评给学生；家长摘要另字段，避免把学生全文作答、逐题解析或私密批注通过“摘要”透传给家长。
- 已graded后首版只读可以接受，但更正/退回/重交/作废应明确未实现；不能再次POST覆盖原始记录。

## 5. 与人工阅卷和成长的衔接

参考paper只能是同机构、同学生、同科目的已confirmed **scored_paper**，排除ability_observation和未复核/OCR-only记录。可只保存最小引用快照（ID、revision、确认时间、来源），不复制原图、OCR文本或其他学生信息。

引用仅供教师核对，不自动将paper总分映射为作业每题分，不自动创建第二份paper。引用变动/失效须明确处理；已经冻结的作业评分以其本身快照和人工分值为准。

growth新增独立homeworkEvidence：只取submitted/graded且有实际提交时间。published只能出现在待办/家长任务摘要，不能进入已学习统计。submitted但未graded的score为null；graded不重复增加提交数。不要与0–3观察、纸卷或在线选择题算成一个“能力百分比”，也不要自动设置pack completed或新增retest。

## 6. 建议验收矩阵（由主任务实际执行）

| 类别 | 必测断言 |
|---|---|
| 内容来源 | 无审核不能创建/发布；机构B不能借机构A的审核；跨科目/跨学生包/超出包范围拒绝；发布前版本变化冲突；发布后原题变化不改快照 |
| 角色与对象 | 学生不能创建/发布/批改；老师不能替学生提交；非负责人即便绑定同学生也不能通过详情/list/summary/growth/sheet导出绕过；家长/admin不读正文 |
| 状态边界 | draft对学生/家长404；published无答案；submitted仍无答案且无分数；graded才有学生反馈和标准解析；未提交不可批改 |
| 提交集合 | 重复/缺失/额外题、非法选项、额外score/key/role字段、超长过程文本全部拒绝 |
| 分值 | 空分不当0、合法0/部分分、负数/超满分/三位小数拒绝；总分按整数百分位准确聚合 |
| 并发与重试 | 两次提交/两次批改只有一次写入；同requestId改内容409；合法重试不重复审计/成长；失败CAS不改明细 |
| 撤销与停用 | owner绑定撤销、家长绑定撤销、teacher/student停用；包括验证后、批处理前撤销的竞态用例 |
| 参考阅卷 | 同学生已确认score paper可引用；观察记录/草稿/外机构/其他学生/科目错误拒绝；不生成重复paper或自动折分 |
| 成长口径 | draft/published不进入；submitted真实记录且score=null；graded在同条证据展示；attempts与pack/retest状态未被作业操作改变 |
| 导出 | 5类新增导出均实际生成；sheet教师/学生均无答案；家长只有摘要；草稿教师可导出且标状态；提交/批改前相应报告拒绝；空列表/网络失败/撤权禁用 |
| 浏览器 | 桌面/手机通过真实登录/发布/作答/批改；响应丢失时提示未确认并能找回；切账号不会串数据；打印不泄露初始密码或标准答案 |
| 兼容 | 原pack worksheet、原JSON/CSV、旧learning/人工阅卷/OCR流程保留；DeepTutor判分反例不被移除或接入正式评分 |

建议JSON/CSV从与页面一致的角色DTO导出，CSV保留公式前缀转义；导出前重新鉴权，当前Actor变更即拒绝。静态端检查入口存在不能替代实际PDF/权限测试。测试只用隔离合成账号，自动化教师审批不是真人题目审核。
