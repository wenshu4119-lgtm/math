## 三级规则示例

| 等级 | 示例资格 | 之后新合格订单的示例奖励 | 单笔上限 |
|---|---|---:|---:|
| 体验分享官 | 成年人自愿，免费，不要求购买或发展他人 | 净合格实付×5% | 100元 |
| 成长推广官 | 3位不同直接有效成交客户，无未处理重大违规，审核生效 | ×8% | 150元 |
| 在线合伙人 | 10位不同直接有效成交客户，身份、规范与协议审核生效 | ×10% | 200元 |

在线合伙人只是推广合作身份示例，不代表股东、法定合伙人、加盟商或劳动关系。无入门费、加盟费、保证金、囤货、招募奖励、团队提成或下级抽成。历史订单锁定成交时的身份和规则，不能升级后追溯提高。

有效期示例为客户本人确认后30天，一笔订单只有一个直接推荐人。观察期、结算周期、月预算、适用服务、税务及兑付渠道仍未确认；新增用于测试的期限和预算必须显示“演练配置”，不视为正式活动规则。

计算使用整数分。例：20000分实际支付、5000分合格退款、500基点比例，结果750分。运费、税费和不符合规则的金额排除；退款区分可计奖部分与已排除部分，避免重复扣除。合格客户数按不同合成客户计算，不以发展推广员或同一客户重复订单升级。

## 状态与审计

推荐：待本人确认→已确认有效／拒绝／到期／纠正；首版使用工作人员人工记录的“模拟客户本人确认”，并明确这不验证真人身份。推广员本人不能把自己推荐的客户直接标记为已确认。

奖励：待核验→待观察／待结算→可兑付→处理中→模拟已兑付；另外有无效、争议、取消与纠正。订单、退款、金额更正和兑付采用提案及不同操作者复核。所有变化保存旧值、当时规则、理由、证据类型、操作者、时间与版本。错误兑付仅更正台账，不能声称撤回真实转账；已兑付后退款保留原记录，进入协议与人工处理，不自动扣银行卡或微信。

## 权限模型

复用账号、HttpOnly Cookie、CSRF及机构边界，增加演练专用operator/reviewer/manager权限。教师不自动拥有财务权限；管理员授予演练权限也不代表真实财务或推广资格。双人复核按不同真实登录账号判断，不能切换页面角色冒充第二个人。普通推广员仅本人脱敏摘要；工作人员按被授权范围处理；未成年人、未知成年状态的学生账号不进入推广演练。

所有私有读取和写入在最终SQL中同时核对当前会话、角色、机构和资源权限。页面拒绝、换号、退出、隐藏及返回时清除或重新认证；打印/导出需重新验权，不把私人台账缓存到Service Worker或localStorage。

## 数据模型

| 实体 | 关键字段与约束 |
|---|---|
| 示例规则版本 | 比例基点、上限分、资格人数、归因天数、观察期、月预算、适用合成服务、生效时间、修改理由；不可用于live |
| 模拟成员／身份历史 | org、user、等级、生效时间、模拟审核状态；不建立上下级字段，不算招募人数 |
| 合成客户／推荐案例 | 不可识别真实人的SIM编号、业务线、唯一直接推荐人、确认/拒绝/纠正、有效期、版本；无姓名电话微信学校成绩 |
| 模拟订单快照 | 唯一SIM订单引用、合成客户、业务线、合格服务、整数分付款/排除项/退款分配、成交时等级及规则 |
| 双人复核提案 | 操作类型、目标、expectedVersion、前后快照、理由、发起人与不同复核人、处理状态 |
| 模拟奖励／兑付记录 | 冻结奖励基数与比例、状态、预算归属、模拟凭证、退款后人工处理差额；没有钱包或提现账户 |
| 申诉与审计 | 本人异议、工作人员处理、不可静默覆盖的事件历史；不公开证据正文给其他推广员 |
| 演练ACL | 机构、账号、operator/reviewer/manager、启停、版本、授予人；不改学习角色 |
| 企业微信配置草稿 | 企业名称、官方公开链接或受保护PNG、人工核验待办、版本、原因；私有草稿，无Secret |

推广表带simulation=1约束，并使用独立迁移0030；联系配置用0031。真实业务请求、正式付款验证、提现、自动转账、真实活动启用、带佣渠道与自动消息在服务端硬关闭。对模拟客户ID的去重不能宣称识别了真人多账号。

## 能力与缺口

目前仅能实现中性体验、工具生成的本平台体验二维码、内部审核素材、独立模拟台账和管理员联系资料草稿。平台二维码不是企业微信二维码。真实联系按钮保持“咨询方式准备中”。

企业微信联系我、获客链接、微信客服、客户联系事件均需各自账号与权限；渠道state或点击事件不能证明客户身份、本人归因、付款或成交。外链及利益诱导分享有平台限制，不通过换文案/二维码规避。企业微信客户ID与支付身份不同，聊天不是支付监管豁免。

需补资料：经营主体与实际服务清单、价格/合同/退费说明、主体和业务资质判断、可使用的宣传渠道、适用服务及奖励预算、真实企业微信公开联系资料及实际权限、成年推广合作协议、身份/税务处理及允许的人工兑付渠道。不得在此表单填密钥或客户资料。
