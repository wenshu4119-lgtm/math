## 设计

公开原表单 → 本地示例预算/任务；登录 → 选择孩子和学段/年度/年级 → 真实报告清单（默认最新有效，缺测可继续）→ 目标与简单时间 → 可展开星期/窗口/停学等设置 → 预览周/日计划及缺口 → 确认保存 → 具体内容/旧作答流程 → 分开记录完成 → 最新复测重排预览 → 确认新版本。

模型：time_plans 当前版本及独立 scope；time_plan_versions 不可变计划快照；time_plan_previews 短期预览，绑定用户、目标版本与证据指纹；time_plan_events 追加实际执行记录。目标/任务/排期快照不改写作答。版本 CAS 与最终同 SQL 授权检查保护并发、撤权及迟到请求；恢复旧版本生成新版本，实际完成记录保留。

时间：日期为本地 YYYY-MM-DD，另存 IANA 时区；开始日包含、目标考试日不排学习；周为周一至周日。净自学口径不再次扣除线下/其他；总预算口径扣除一次。固定时段互不重叠，暂停优先；周总量含已固定部分，剩余部分才另排。休息和任务容量冲突显示未安排，不挤占休息。预计时间均为估算，不推算目标分差或达标概率。

内容：只读实际库/报告，要求当前版本和审核可用。旧初中内容是简短知识讲解，不称完整教材讲义。艺考未审核版本保留缺口。报告少于 5 题和超过 30 天显示规划提示（产品启发式阈值，不是科学能力诊断）。未测不判不会；用户历史分只作独立自填快照，不用于换算平台成绩或地理/政治赋分。

中考没有全国统一满分；用户配置考试名称、科目上限、总上限及来源，未核验清楚标示。湖北 2026/2027 原始分/等级分规则按省考试院对应报名须知核查；预计考试日期由用户指定，不预设为官方确定安排。
