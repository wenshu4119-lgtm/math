## 独立方法和限制

1. `math-blind-source-v2.json` 冻结158题的题干和四选项，不包含答案字段、解析或原自动检查表达式。每题都有题干/选项哈希和原规范内容哈希。
2. `src/question-bank-validation-v2.mjs` 为每题建立可读的独立数学推导。数值题重新计算；方程与不等式核对定义域和端点；几何题给出定理或坐标推导；概率题独立枚举样本空间。特殊形式题（科学记数法、全等判据等）同时核对题面要求，不能只比较数值相等。
3. 先生成独立答案并检查全部选项，再与原答案键比较。没有执行任何来自题库的JavaScript或相信原 `automatedCheckResult`。
4. 独立解答完成后，逐条读取原解析，核对数学步骤、边界条件、结论和图形位置假设；冻结其哈希到 `math-rationale-review-v2.json`。任何新题干、选项或解析不能继承旧结论。
5. 每题分别记录答案、唯一性、解析、必要图示、年级与教材适配、来源权利和难度。知识/题目难度仍使用超低、低、中等、高、超高，保留原初标，不以筛查/练习/复测代替难度。来源仍是原稿原创CC0声明，未将其升级为外部版权认证。

这是有限题面绑定的规则与独立推导，不是通用定理证明器。推导由AI助手编写、代码重算，并由根线程抽检；不是教师签名审核，不可宣传整体AI准确率。来源教材顺序、当地学段安排、地区中考范围和实际难度仍需教师核定。几何通过题依据明确文字条件与通常的线段、三角形、矩形等数学定义，不意味着已经补齐所有有助教学的示意图。

## 增量批次与冲突保护

交给根应用器的文件是 `data/question-bank/rechecks/math-recheck-v2.json`。使用统一schemaVersion 2：顶层 `records`，`batches` 通过 `questionIds` 引用记录。每题携带：

- `expectedRevision: 1` 与 `sourceContentHash`；proposal中再次明确 `expectedRevision`、`expectedContentHash`。
- 完整原规范题目 `content` 与相同 `contentHash`，本轮没有静默修改题干、答案、解析、难度或来源。
- 新自动核验 `validation`、拟议状态 `available` 或 `quarantined`，以及逐项证据。
- `humanReview: false`、`teacherReviewed: false`、`formalGradingAllowed: false`。

根应用器还须检查当前版本仍是原始import、原状态未被教师改变且 `reviewed_by IS NULL`。教师修改过、撤回过、已审核或产生新版的题必须CAS跳过并列冲突，不能覆盖。批次应用应生成不可变新版本和批次日志；回滚以新历史记录恢复旧状态，不能删除版本或覆盖后来教师操作。实际应用与回滚由根线程负责，本代理未连接生产写入。

源catalog哈希、checker源代码哈希和proposal checksum保存在报告中。批次ID稳定；重复生成保持首次checkedAt和完全相同checksum。将来修改规则应升级checker/batch版本，不能用同一批次ID覆盖已经应用的不同内容。
