# 分批题库上线与回滚交接

本交接不表示已经生产发布。生产状态以发布线程实际部署、导入结果和线上探测为准。

## 源文件与独立审核

2026-11-14 实读 `platform-ui/question-bank/draft-question-bank.json` 和 `draft-question-bank-vol2.json`，分别 270/54 题、90/18 知识点，共 324 题、108 知识点。来源文件的 SHA256、字节数、修改时间、来源与 CC0 声明及每个原始批次分区保存在 `data/question-bank/audit.json` 和 `catalog.json`。作者声明 CC0 并不等于第三方权利认证；没有擅自混入外部教材题。源文件中的 `independentVerified:true`、`automatedCheckResult` 和 JavaScript 表达式不作为验证结论或被执行。

本轮严格从题干解析可验证的算术，仅 4 题独立自动通过；317 题需要教师语义、图形、解析与适配审核；3 道英语存在多种合理语境的严重疑点，先隔离：

- `draft-en-g8-indefinite-pronouns-freq-diag`：something interesting / anything interesting 均可出现在疑问句，缺少限定语境。
- `draft-en-g8-perfect-adverbs-yet-already-diag`：already / yet 均可能用于该问句，不应把常见教学倾向当唯一语法答案。
- `draft-en-g8-present-perfect-prac`：has gone / went 在现有语境中都可能成立，需要明确时间/考查条件。

这三题是“疑点隔离”，不是声称最终教师裁决；原题与答案完整保留。其余题未自动通过不等于发现错误。几何与英语的人工复核提示保留。必要图片显式引用而图片缺失、字段错误、答案错误、选项重复、来源不明会隔离。

4 道数学是有理数混合运算、有理数乘方、二次根式混合运算、特殊角三角函数各 1 题，覆盖初一 2 / 初二 1 / 初三 1。它们只用于不计正式成绩的自主练习，尚无真人审核。原有 4 知识点/12 示例题保留，仍受旧正式测评教师审核门禁保护。未将新题库自动写入旧 questions、attempts、answers 或成长记录。

## 实际流程和权限

教师/管理员入口 `/question-bank.html`，学生/教师练习 `/bank-practice.html`。未登录、家长不能读答案题库；管理员不能冒充老师执行审核。老师按机构检索学科、年级、知识点、题目/知识难度、用途、状态、审核状态；分页每页最多100题。具体题目可查看源声明、解析、自动疑点、历史版本和举报，执行纠错、退回、真实逐题审核、独立发布、撤回、举报处理。管理员可导入打包且已核验的批次，重复源哈希自动跳过。此版本不接受浏览器任意上传外部JSON；新增源先在服务端审计、打包、部署，再按批次导入。

难度统一为超低、低、中等、高、超高。题目原稿1/2/3仅映射为低/中等/高初标，保存依据；不得编造超低/超高。知识点原稿没有独立难度，默认为待定级。知识点统一难度有机构内独立版本记录，跨题一致；题目内容历史另保留当时知识难度快照。筛查/练习/复测/中考综合是独立用途；中考综合可关联同学科多个已入库知识点，但当前未自动宣称已有中考综合成卷。

题干、答案、解析等修改产生不可变新版本，原审核自动失效，停止该题自主练习直到重新审核发布。历史不会覆盖。老师审核需逐项确认答案、解析、来源、年级、唯一性、必要图示，记录真实用户、时间、版本、内容哈希和检查项目。退回和撤回也保留版本。JSON/CSV导出带版本与审核状态；PDF使用鉴权后的打印视图，只有真实审核后出现“老师已审核”。

练习列表不返回答案；选择后按相同版本返回解析，不保存正式成绩，不宣称能力提升。老师审核通过再发布的内容也只进入该机构自主练习/教师选题；尚未接入旧正式评分协议。当前纠错工作流不会静默改写任何既有成绩或作答快照。教师可逐题工作，无须先审完整库。

匿名 `/api/v1/public/coverage` 只有全站聚合数据，不含答案、题干、学生或教师身份。按题目ID去重；审核/可用数表示至少一个机构拥有该状态，不代表所有机构已获得同一审核/授权。各机构业务读取仍单独鉴权。隔离空测试库初次导入为336题/112点（含旧12/4），老师已审0、未审336、隔离3、自主练习4。正式库已观察到原4知识点审核记录、12原题已审核，因此保留生产数据后预计336题/112点、老师已审12、未审324；最终必须以线上真实查询核定。正式评分可用由各机构旧真实审核记录决定。

## 九科与中考建设计划

| 学科 | 首批实际内容 | 后续范围与适配约束 |
|---|---|---|
| 语文 | 0题 | 初中阅读、语言积累、写作知识与任务；主观题需教师量规，先确认当地教材、地区考试要求 |
| 数学 | 162新题/54点，含4题自主练习；另6原例题/2点 | 初一至初三，先补现有章节的唯一答案/几何图示审核，再按本地教材补章；跨章综合单独标用途 |
| 英语 | 162新题/54点，全部未人审，其中3隔离；另6原例题/2点 | 初一至初三，优先语境唯一性、语言真实性、听力材料权利、教材词汇范围；不以词汇题冒充全技能覆盖 |
| 物理 | 0题 | 按机构实际开课年级建库，不编造未开课年级；实验图、电路图、量纲独立检查 |
| 化学 | 0题 | 按机构实际开课年级建库；先核化学式、反应条件、实验安全和图示 |
| 生物 | 0题 | 按地区学段、教材与结业考试安排建库；图示来源及事实需学科教师核定 |
| 历史 | 0题 | 按当地教材册次；史料出处、时间线及材料题量规需核实 |
| 地理 | 0题 | 按地区学段及考试安排；地图授权、图例、比例尺和最新地理事实需核实 |
| 道德与法治 | 0题 | 按实际教材/年级/地区；时事与法律内容须按版本标时效并由教师审核 |
| 中考综合复习 | 尚未形成独立成卷 | 独立用途/专题，不是难度；允许跨章节知识关联，按地区考试方案和教材范围再标注 |

每一批均先保存原始文件哈希和声明、独立校验报告、隔离清单，再导入教师库；仅满足可用条件的小批进入自主练习。不存在“全科已完成”的承诺。

## 部署文件与导入

服务器需包括 `data/question-bank/catalog.json`、`data/question-bank/audit.json`、`src/question-bank*.mjs`、迁移0007、导入CLI以及更新后的API路由。答案文件绝不能放在 public。数据库先按发布协调流程加密备份并验证恢复，然后在停写窗口执行：

```text
node scripts/import-question-bank.mjs --database /var/lib/learning-platform/data/learning.sqlite
```

仅当数据库恰有一个机构时可省略 `--org`；否则须指定机构ID。可用 `--batch <服务端已打包批次ID>` 限定导入卷，重复执行只跳过已导入源hash。不创建账号、不写老师审核、不修改旧题或成绩。CLI退出成功会输出导入/跳过与状态统计。服务端新导入表按机构隔离，旧题表不变。

新增功能可先回滚后端/静态版本（保留向后兼容新增表）；不可删除版本历史。内容撤回用教师页面生成withdrawn新版本；历史保留。整库恢复必须停止写入并按发布线程已有SQLite/图片一致性备份恢复，不覆盖运行中的WAL。源catalog/audit可按对应release完整回滚，新旧源hash不会被静默替换。

## 检验边界

业务测试覆盖独立算术、答案错误/多解/缺图隔离、幂等导入、组织与角色隔离、真实老师审核、版本冲突、修改失效、撤回、举报、导出、知识点统一定级、读取历史期间撤权及审核提交期间角色撤销。浏览器使用合成账号和隔离数据库；真机按用户要求未测。PDF通过桌面/手机视口生成，中文/A4/边界自动检查并逐页渲染目检。未对完整324题给出自动语义正确性认证，未覆盖所有教材地区，未完成全科扩充或正式评分接入。
