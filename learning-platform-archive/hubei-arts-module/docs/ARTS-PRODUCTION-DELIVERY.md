公开题与受保护题的题干、题号、答案映射独立。演示只根据当前访客实际点击展示本地题结果，不上传、不写入账号；不把合成测试账号或自动化审核当真实学生、真人教师或提分证明。

## 已实现的真实功能

- 按机构、授权学生、学段、年度及学科保留独立数据；学生本人、绑定教师、授权家长采用不同视图。
- 目标和时间预算、前置与近期错因建议、有原因的教师调整；排序规则显式展示，无预测得分。
- 具体版本的审核、纠错和严重问题隔离；改题后重新审核，历史作答保留快照。
- 筛查→讲义与练习→复测，保存实际选择及学生自主／教师代录来源；未提交可恢复。
- 同范围、版本、标注难度才比较；严重隔离证据不参与进步结论。
- 家长不读取逐题答案或教师内部备注。PDF／打印前重新验证权限；默认直接打印隐藏私人正文，换号、失权或离开页面清除私人状态。
