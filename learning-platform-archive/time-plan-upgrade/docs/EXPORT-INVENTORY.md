## 分工与统一约定

- 后端是权限与数据来源唯一依据。导出不相信 localStorage 角色、前端 `_isMock`、客户端分数或缓存数据，不增加跨学生聚合权限，不写入业务记录。
- 前端 `print.html` 独立预览页按 registry 调用真实 `/api/v1`，无第三方 PDF 服务；中文、原生 MathML、矢量 SVG 图表与授权图片由浏览器渲染，统一 `print.css` A4、16mm 左右/上边距、18mm 下边距。
- 每个导出都带内容来源、时间、学生别名（适用时）、审核/示例状态。未提交题目不带答案，待审核内容明确标注。
- 导出按钮先进入预览；加载、空内容、401/403/404、503、图片失败时禁用打印并显示具体信息。勾选预检后再次读取数据和权限，确认没有变动才打开系统打印。
- 真实产品出口为浏览器「打印 / 另存为 PDF」，不是伪装成直接下载；浏览器取消打印不报告为成功。代码不宣称已知道用户文件是否落盘。
- 禁止缓存 API、私有图片、print 页面；会话/业务内容只在页面内存。刷新和打印前重新授权；撤权后无法再次导出，已保存到用户设备的文件无法追溯撤回。
- 标题随正文、题目块、图表和正常尺寸图片尽量整块分页；超过一页的长文本显式允许跨页，长表重复表头；超大图片限制在一页内。超长单题须预检警示并人工检查分页。
- 桌面与手机共享 A4 打印规则，手机屏幕预览按宽度流式显示。浏览器/系统打印能力和字体存在差异，不能把桌面浏览器移动视口测试宣称为真实 iOS/Android/鸿蒙设备验证。

逐项实际验证状态、生成文件和未覆盖项以 `docs/VERIFICATION.md` 和 `test-results/pdf/summary.json` 为准；这张实施清单本身不等于测试通过。
