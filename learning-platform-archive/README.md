# Learning platform source archive

Read-only backup snapshot dated 2026-11-17. Original math root files are unchanged. This branch does not deploy any service.

The eight directories preserve independent work versions; they are not merged and are not all production-ready. junior-learning-release is the production integration working copy.

UPLOAD-MANIFEST.json lists source files and hashes. WITHHELD-FILES.json lists conservatively withheld candidates. Runtime state, credentials, dependencies, local databases, binary archives, output and test artifacts are excluded. Credential-like test literals may also be withheld conservatively. Restore credentials separately; do not publish secrets. This archive is not a full runnable or data backup.

Verified inventory: 3,249 source files plus these 3 archive metadata files, 3,252 added files total. 310 candidate files were withheld in addition to excluded runtime/dependency directories. SHA256 values describe original local file bytes; Git text line-ending normalization may differ.
